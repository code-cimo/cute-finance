# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-01-15

### Added
- 🎉 Initial release of CuteFinance PWA
- 🐾 5 cute animal mascots (Panda, Shiba, Bunny, Capybara, Cat)
- 💰 Multi-currency support (IDR, USD, EUR, JPY)
- 📊 Professional budgeting engine with 3 allocation rules
- 📱 Mobile-first PWA with offline support
- 🎨 Pastel color palette with smooth animations
- 📋 Transaction management with categories
- 📈 Statistics dashboard with charts
- 🔔 Payday notification system
- 💾 LocalStorage data persistence
- 📤 Export/Import data (JSON & CSV)
- 🎯 Budget progress tracking
- 🔥 Streak counter for gamification
- 💡 Daily financial tips
- 🎊 Confetti celebration on transaction add
- 📲 PWA install prompt
- 🐳 Docker deployment support
- 📦 Automated installer script
- 📚 Comprehensive documentation

#### Dashboard

#### Transactions
- Quick add with FAB button

#### Settings

- Data export (JSON/CSV)
